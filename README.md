# 📚 Lecture Parser Telegram Bot

A Telegram bot that parses lecture information from text and auto-detects Subject & Chapter.

## ✨ Features

- 🔢 Extracts **Index**, **Title**, **Quality**, **Lecture Number** from lecture text
- 📚 Auto-detects **Subject** (Physics, Chemistry, Biology, Botany, Zoology)
- 📖 Auto-detects **Chapter** using fuzzy string matching
- 🎯 Reply Format: `@Subject` → `@Chapter` → `@Lec XX`
